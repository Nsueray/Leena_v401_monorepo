ℹ️ Help
Terminal Management — Manage scanner devices for this expo. Each terminal has a unique Terminal Key for authentication — no login needed.
  • Create a terminal → Get a unique Terminal Key
  • Open scanner page on any device using the terminal URL
  • Deactivate a terminal without deleting it
Terminal Yönetimi — Bu fuarın tarayıcı cihazlarını (check-in istasyonları) yönetin. Her terminalin kimlik doğrulama için kullanılan benzersiz bir Terminal Key'i vardır — kullanıcı adı/şifre gerekmez.
  • Terminal oluşturun → Benzersiz bir Terminal Key alın
  • Herhangi bir cihazda (tablet, telefon, laptop) terminal URL'sini kullanarak tarayıcı sayfasını açın
  • Bir terminali silmeden deaktif edebilirsiniz
