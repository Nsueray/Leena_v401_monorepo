Visitor Log — Complete list of all registered visitors for this expo. Search by name, email, company, or badge ID. Use filters to narrow results. Export to Excel for offline use.
  • Each visitor has a unique Badge ID and QR code that never changes
  • Check-in status shows whether the visitor has entered the event
  • Visitors register via: public form, import, webhook, or reactivation
