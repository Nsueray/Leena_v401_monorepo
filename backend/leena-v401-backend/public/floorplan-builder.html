Floor Plan

ℹ️ Help
Floor Plan Builder — Visual tool for creating expo floor plans. Select cells → Create Stand. Each cell = 1m².
  • Draw mode: drag to select cells → Create Stand
  • Select mode: click stand to edit, Shift+click for multi-select, drag to move
  • Split, Merge, Clone, and Export available
  • Middle-mouse or Space+drag to pan, scroll to zoom
Kat Planı Editörü — Grid hücrelerine tıklayarak stand oluşturun. Her hücre = 1m².
  • Draw modu: sürükleyerek hücre seçin → Stand Oluştur
  • Select modu: tıkla-düzenle, Shift+tıkla çoklu seçim, sürükle-taşı
  • Split, Merge, Clone ve Export mevcut
  • Orta tuş veya Space+sürükle: kaydır, scroll: zoom
