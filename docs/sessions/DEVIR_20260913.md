## 3. Report-scheduler fix (13 Sep push)

**Fixed in this push** — `email_worker.js maybeFireCallCenterDailyReport()`:

- Root cause: `casaTodayStartUtcCC()` returns a UTC ts of Casa
  midnight + 1 h due to a `new Date(<Casa-formatted string>)`
  round-trip on UTC servers. At 23:00-23:59 UTC the boundary lives
  in the future; probe boundary jumps past just-inserted rows.
  Result: 12 fires per night. Verified against ground truth Sep
  11→12 and 12→13.

- Fix: (a) rolling-window probe `created_at >= NOW() -
  INTERVAL '20 hours'` — no Casa/UTC date math. (b) hour cap `18
  ≤ utcHour < 23` — blocks the 23:00-23:59 UTC window entirely.

## 6. Paste-vs-file lesson

Chat sessions occasionally lose long attachments. **Rule**: any
output >50 lines goes to a file (`.md`, `.csv`, `.txt`) and gets
attached rather than pasted inline. Chat file attachments survive;
inline pastes can silently truncate in long sessions.

Screenshots / renders → PDF or PNG attachment, not inline. DB
query results >50 rows → `psql -Ac "..." > /tmp/out.tsv` then
attach the TSV.
